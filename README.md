# PPT-style · 个人 PPT 风格提炼与分层写 PPT 工坊（V0.1.1）

> 不用懂代码、AI 术语或规则语法，把你写 PPT 的“布局逻辑、表达口吻、排版审美”炼成你的专属助手，日常按需要一句口令直接调用。

---

## 为什么好用（3 个核心设计）

1. **一次提炼三层，日常按需单点**：建档时一次学完「页面规划 → 单页内容 → 视觉排版」；平时写 PPT 可以全套代写，也可以只要大纲、只填内容，或“定稿文字一字不改、只美化排版”。
2. **合写长稿不用拆，免逐页填表**：把多人合写的完整 PPT 直接丢进来、口头说一句哪几页是你的即可（绝不让你自己建空白 PPT 复制粘贴毁掉原配色），省掉繁琐手工标注。
3. **原地改完保存即学习**：AI 出的稿在原文件改完直接按 `Ctrl+S` 保存就能自动比对进化；电脑全局只装这一个技能，支持多场景风格切换与一键回滚。

## 三步快速开始

### 第 1 步：安装技能（两种方式任选其一，仅需 1 次）

#### 方式一：直接让你的 AI 帮你装（最推荐，自动对齐当前软件目录）
打开你的桌面 AI 软件（如 Trae / Cursor / Claude Code / Antigravity 等），直接复制下面整段话发给它：

```text
请帮我安装这个 GitHub 技能：https://github.com/coolsprite91/PPT-style
请严格按下面 4 步做，不要跳步：
1. 先核实你当前这个客户端真正会加载的“全局技能目录”在哪里（对照你现有已加载技能的路径，不要盲猜默认路径）；
2. 把这个仓库里的技能文件完整安装到你真正读取的那个目录里（建议目录名统一用全小写 ppt-style；如已有同名旧版，请备份到技能目录之外，不要留在同级文件夹下干扰识别）；
3. 如果你没有权限往全局目录写文件，请改安装到当前工作区你能读取的本地技能目录，并如实告诉我；
4. 装完后请用大白话告诉我 3 件事：① 实际装进了哪个路径；② 我要“新开对话”还是“重启软件”才能生效；③ 新开对话后我发哪一句口令，能立刻验证你真的读到了这个技能。
```

#### 方式二：下载压缩包后双击一键安装
从 GitHub 页面右上角点击绿色 `Code → Download ZIP` 并解压：
- **Windows**：双击 `install_windows.bat`
- **macOS**：双击 `install_mac.command`  
*(安装器会自动扫描你电脑上已装的多款主流 AI 软件技能目录并同步写入，机读目录统一规范为小写 `ppt-style`)*

### 🔍 3 秒验证是否真装好了（必做）

**新开一个对话窗口**（如仍没反应可重启一次软件），发送这句暗号：

```text
检查 PPT-style 是否就绪
```

- **看到回复开头出现 `【PPT-style V0.1.1 已激活就绪 ...】`** → 说明真的加载成功了，可放心进入第 2 步！
- **如果 AI 没有回这句固定格式、只是顺着你的话随便聊天** → 说明刚才装错了文件夹，直接把这句发给当前窗口排障：  
  *“你没加载到 ppt-style 技能，请把你刚才安装好的文件夹挪到你当前真正读取的技能目录里，再告诉我重启还是新开对话。”*

### 第 2 步：建工坊、提炼风格
1. 在确认激活的窗口说：**`帮我建 PPT 风格工坊`**。
2. 放入至少 **1 份 `.pptx` 代表作**（越多越准，支持直接传文件或发文件夹路径；多人合写稿告知你的页码或大致内容即可）。
3. 先看 AI 生成的 **1 页预览样稿** 确认色调与留白顺不顺眼。
4. 答完 **1～2 轮核心单选题**（每轮最多 5 题）后，AI 会明报还剩几道偏细节的问题——可以直接选**“先开用，细节留待以后改稿顺手学”**，改两笔试炼稿保存即建档完成。

### 第 3 步：日常直接开口使唤
以后在任何工作目录开新对话，直接按下面的场景口令使用。

## 日常 5 档调用速查表

| 场景 | 直接这样对 AI 说 | AI 会为你做什么 |
|---|---|---|
| **1. 全套代写** | “帮我基于这些资料做一套季度汇报 PPT” | 先定分页框架 → 再填每页内容 → 最后排版出稿（步步确认） |
| **2. 只做页面规划** | “先帮我规划这套汇报分几页、每页讲什么” | 输出总页数、整稿逻辑与每页概要，以及还缺什么数据资料 |
| **3. 按大纲填内容** | “这 6 页框架定了，帮我把每页具体内容写出来” | 锁死你的页数与结构不乱拆改，写好标题、论据、表格和备注 |
| **4. 定稿只美化排版** | “文字已经定稿了，一字不改帮我按我的风格排版” | 核对数字和正文一字不改，按你的安全留白网格排成可编辑 PPT |
| **5. 旧稿局部加页** | “在这份 PPT 第 5 页后面新加两页，别的页别动” | 其余页面原封不动，仅在指定位置插入对齐周边画风的新页 |

> **临时借用外部参考 PPT**：在上面任意一步顺手丢入领导模板或参考稿说“样式按这份参考”，AI 会先跟你说清楚“哪部分按参考稿调整、哪部分保留你个人习惯”，且默认仅本轮临时生效。

## 随时可用的管理与反悔口令

- **撤回与清理**：`修改上一题` · `查看我的风格规则` · `删除第 3 条习惯` · `回滚到上一个版本` · `恢复默认设置`
- **多风格与换公司**：`新建一套“对外客户提案”视觉风格` · `切换到对外提案风格` · `保留我的写作习惯，只换新公司视觉模板`
- **分享给同事**：`把我的这套风格导出成一个可分享的安装包`

## 运行前提与常见问题

- **电脑环境要求**：支持本地运行脚本的桌面端 AI 客户端。读旧稿、做规划、写逐页文案与手改比对做到 **0 额外插件安装**；仅在最后生成可编辑 `.pptx` 时需要轻量写稿组件（缺失时 AI 会明示提示一键安装，拒装也可直接拿到结构完整的逐页文案稿）。
- **只有 `.ppt` 或 WPS 的 `.dps` 怎么办？**：请在 PowerPoint 或 WPS 中点击「文件 → 另存为 → 选择 `.pptx` 格式」后再传入，这样才能完整保住配色和字体。
- **改稿时文件正开着、或没另存副本怎么办？**：不用手动另存副本。原地按 `Ctrl+S` 保存后说“我改好了”，后台底稿会自动对齐比对；如写入更新时文件正被办公软件占用，会自动另存为 `-v2.pptx` 不逼你反复关窗。
