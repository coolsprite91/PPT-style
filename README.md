# PPT-style · 个人 PPT 风格提炼与分层写 PPT 工坊（V0.2.1）

> 不用懂代码、AI 术语或规则语法，把你写 PPT 的“汇报场景套路、单页框架、视觉母版审美”炼成可自由组合的专属助手，日常按需要一句口令直接调用。

---

## 为什么好用（4 个核心设计）

1. **三层积木自由拼装**：建档时分别沉淀「**L1 写稿场景**（如月会/复盘/方案/提案）→ **L2 场景下的多套单页框架** → **L3 多套真实母版皮肤**」。平时可以按场景一键全套出稿，也可以口头混搭（比如“用项目复盘框架，套对外提案深色模板”）。
2. **合写长稿自动分诊防串味**：丢进一整个文件夹也不怕，自动识别多人合写稿并提醒你一键去掉或只标出本人页码，绝不把同事的画风学成你的习惯。
3. **多轮人机交替手改不断链**：你改一轮、AI 接着改、你再改一轮——全程按隐形编号记住修订时间线，既能每次只看最新改动，也能最终只汇总你的纯人工偏好，不把 AI 改的误学进来。
4. **遇坑明说降级、开口即查用法**：缺组件或受加密保护时，先用三句话讲清原因和影响等你同意再降级；提炼完立刻发给你一份大白话速查表，忘了怎么用随时问一句“怎么发起写 PPT”就能原样再看一遍。

## 三步快速开始

### 第 1 步：安装技能（两种方式任选其一，仅需 1 次）

#### 方式一：直接让你的 AI 帮你装（最推荐，自动对齐当前软件目录）
打开你的桌面 AI 软件（如 Trae / Cursor / Claude Code / Antigravity 等），直接复制下面整段话发给它：

```text
请帮我安装这个 GitHub 技能：https://github.com/coolsprite91/PPT-style
请严格按下面 4 步做，不要跳步：
1. 先核实你当前这个客户端真正会加载的“全局技能目录”在哪里（对照你现有已加载技能的路径，不要盲猜默认路径）；
2. 把这个仓库里的技能文件完整安装到你真正读取的那个目录里（目录名统一用全小写 ppt-style；如已有同名旧版，请备份到技能目录之外，不要留在同级文件夹下干扰识别）；
3. 如果你没有权限往全局目录写文件，请改安装到当前工作区你能读取的本地技能目录，并如实告诉我；
4. 装完后请用大白话告诉我 3 件事：① 实际装进了哪个路径；② 我要“新开对话”还是“重启软件”才能生效；③ 新开对话后我发哪一句口令，能立刻验证你真的读到了这个技能。
```

#### 方式二：下载压缩包后双击一键安装
从 GitHub 页面右上角点击绿色 `Code → Download ZIP` 并解压：
- **Windows**：双击 `install_windows.bat`
- **macOS**：右键 `install_mac.command` → 打开（避开系统未签名拦截）  
*(安装器会自动扫描你电脑上已装的多款主流 AI 软件技能目录并同步写入，支持常见客户端与软链目录)*

### 🔍 3 秒验证是否真装好了（必做）

**新开一个对话窗口**（如仍没反应可重启一次软件），发送这句暗号：

```text
检查 PPT-style 是否就绪
```

- **看到回复开头出现 `【PPT-style V0.2.1 已激活就绪 ...】`** → 说明真的加载成功了，可放心进入第 2 步！
- **如果 AI 没有回这句固定格式（或提示找不到技能）** → 按下面 4 步发给当前 AI 排查：
  1. 让 AI 先查它当前已经生效的任意一个技能放在哪个文件夹；
  2. 检查文件夹名是不是全小写 `ppt-style`、`SKILL.md` 是不是在第一层目录（别因解压多套了一层文件夹）；
  3. 检查同级目录有没有留下旧版备份目录抢触发；
  4. 确认是不是需要彻底重启软件，或该客户端需要从设置面板导入规则，挪对后再新开窗口验证。

---

### 第 2 步：建工坊、提炼风格
1. 在确认激活的窗口说：**`帮我建 PPT 风格工坊`**（默认落在个人 `文档/我的PPT风格工坊/`，也可以直接说你想指定的文件夹位置）。
2. 放入至少 **1 份 `.pptx` 代表作**（直接上传或给文件夹路径都行；如果里面混了多人合写稿，AI 会先分诊提醒你一键去掉或只报本人页码）。
3. 先看 AI 用真实母版生成的 **1 页《纯视觉皮肤预览》**，确认要留哪几套模板、要不要开启安全留白微调。
4. 确认你的 **主要写稿场景**、各场景下的 **页面框架**（置信度一般的框架 AI 会给你调整建议让你拍板），以及 **母版和场景的绑定/独立关系**。
5. 改两笔组合试炼稿保存，建档完成！AI 会自动发给你一份**按你真实场景定制的调用速查指南**。

## 日常 5 档调用速查表（忘了随时问“怎么发起写 PPT”）

| 场景 | 直接这样对 AI 说 | AI 会为你做什么 |
|---|---|---|
| **1. 全套代写** | “帮我按我的月会风格，基于这些资料做一套 PPT” | 口语确认目的和资料 → 定大纲 → 写每页内容 → 套对应母版出稿 |
| **2. 只做页面规划** | “先帮我规划这套汇报分几页、每页讲什么” | 只要目的和粗略主题（不用细数据），输出页数、骨架和每页大纲 |
| **3. 按大纲填内容** | “这 6 页框架定了，帮我把每页具体内容写出来” | 锁死你的页数与结构，区分数据页和品牌观点页，写出正文与讲者备注 |
| **4. 定稿只美化排版** | “文字已经定稿了，一字不改帮我按我的风格排版” | 数字和文字一字不改（未分页长文先问切页），按安全留白排成可编辑 `.pptx` |
| **5. 旧稿局部加改页** | “在这份 PPT 第 5 页后加两页（或只改第 3 页），别的页别动” | 其余页面 100% 原封不动，支持插入新页或原地替换指定页 |

> **随时查怎么用**：任何时候忘了口令，直接问 **`怎么发起写 PPT`** 或 **`怎么调用我的风格`**，AI 会按固定 5 段速查格式回答你。

## 随时可用的管理与反悔口令

- **撤回与清理**：`修改上一题` · `查看我的风格规则` · `删除第 3 条习惯` · `回滚到上一个版本` · `恢复默认设置`
- **场景与母版混搭**：`用我的项目复盘框架，但视觉换成对外提案皮肤` · `把这套模板绑给月会场景` · `保留我的写作习惯，只换新公司视觉模板`
- **分享给同事**：`把我的这套风格导出成一个可分享的安装包`

## 运行前提与兼容说明

- **三句话显式降级**：不管缺少写稿小组件、被软件限制权限、没装 Python 还是文件被公司加密软件锁住，AI 都不会悄悄降级或糊弄，一定会先用“① 因为什么原因 → ② 会有什么影响 → ③ 你接不接受先按降级效果继续”三句话和你确认。
- **跨软件格式支持**：老式 `.ppt`、WPS `.dps`、苹果 Keynote `.key`、`.odp` 以及疑似透明加密的文档会自动识别并给出 2 步导出 `.pptx` 或转 PDF 走纯对话模式的指引，不会卡住整批文件。
- **多轮手改与防占锁**：AI 建稿 → 你改一轮 → AI 接着改 → 你再改一轮，全程自动继承追踪、绝不吞掉前轮手改；正开着 PPT 没关时写盘会自动另存为 `-v2.pptx`。
