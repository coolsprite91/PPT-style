# 01｜风格提炼向导操作规范（V0.2.0 · 第 0～6 步）

> 适用场景：新建工坊、从代表作提炼三层积木风格资产、以及后续追加新代表作增量更新。

---

## 一、第 0 步：冷启动、三句话显式降级与工坊选址

1. **环境探测先行**：每次开启先跑 `env_probe.py`（自动实测真实 Python 3，规避 macOS `/usr/bin/python3` Xcode 假桩与 WindowsApps 空壳，自动识别 Windows OneDrive 同步文档路径）。
2. **三句话显式降级确认（硬规定，绝不静默降级）**：
   一旦 `degradation_tier != "FULL"`（例如缺 `python-pptx`、沙箱禁止写个人主目录、无 Python / 网页端 / 公司透明加密锁住文件），**必须先发三句话给用户拍板**：
   - ① **原因**：一句话说清卡在哪（如“这台电脑还没装自动生成 PPT 的小组件”或“当前软件限制了全局目录写入”）；
   - ② **影响**：明说降级后什么能用、什么受限（如“读旧稿、定大纲和写内容正常，只是出稿改为带排版指令的逐页文案稿”或“改用传图/PDF 走纯对话提炼”）；
   - ③ **询问**：`请问你能接受先按这个降级效果继续吗？（A. 接受，直接继续 / B. 暂不继续，先按步骤补齐环境）`
3. **工坊落点规则（尊重指定 ＋ 防污染默认）**：
   - **未指定工坊位置**：默认落在个人文档区 **`我的PPT风格工坊/`**（Windows 优先识别 OneDrive 同步目录），**绝不默认塞进当前打开的业务项目目录**，避免几十份历史稿污染业务仓库。
   - **用户显式指定工坊位置**：**100% 按用户指定位置初始化**，并写入全局索引支持跨窗口说“继续”断点续跑。若指定目录无写权限，立刻明说请换路径；若位于 Git 仓库内，自动写入工坊 `.gitignore` 并轻提醒一句。
   - **仅给出旧 PPT 存放文件夹**：默认“工坊仍建在个人文档区，只读引用你的旧 PPT 文件夹、绝不往原文件夹塞杂文件”；除非用户明说要建在里面。
   - **对话框手动上传文件**：不管工坊在哪，一律强制传入 `--from-upload` **物理拷贝**进工坊原始归档区，严禁引用临时上传缓存路径。

## 二、第 1 步：收样、跨软件拦截与多人合写预分诊

### 2.1 开场白话引导
向用户说明三点（控制在 5 行以内）：
- **代表作数量不设上限**：传得越多，提炼越准、覆盖的场景越全；但样本越多，后台分析耗时和后续确认轮次也会相应增加。至少需要 **1 份 `.pptx`**；
- **怎么传都行**：直接拖进对话框，或给本地文件夹路径，原件绝对只读不损坏；
- **合写稿不用拆**：千万别自己新建空白 PPT 复制粘贴（会毁掉原配色），把整份丢进来即可。

### 2.2 跨软件格式、透明加密拦截与多信号合写预分诊
1. **目录分诊与格式拦截**：运行 `workspace_manager.py scan-dir` / `triage`：
   - 超过 **20 份**或 **500 MB** 自动改用 `--copy-mode reference` 轻量只读引用（上传文件除外）；
   - 遇到老式 `.ppt`、WPS `.dps`、苹果 Keynote `.key`（含文件夹包）、`.odp` 或加密稿，给出对应软件 2 步自助导出 `.pptx` 指引并跳过继续处理其他正常文件；
   - **疑似公司透明加密**：若 `.pptx` 非空但读出来既非正常压缩包也不是老式格式，明示“软件里能开但脚本读成乱码，大概率是公司加密软件保护了文件；建议在非加密区另存，或先导出 PDF 发我走纯对话降级模式”；
   - 同源迭代改稿（内容相似度 ≥ 72%）自动折叠，推荐只留最新主版；>50MB 含音视频流文件自动剥离音视频轻量化留底。
2. **多人合写稿多信号预分诊与三选一收口**：
   - 自动结合“文档作者属性、文件名汇总/月会/人名特征、内部多母版、页内多汇报人署名、同母版页段风格突变”分出绿组（纯个人）/ 黄组（疑似合写）/ 灰组（纯模板）。
   - 对黄组文件必须显式发出防串味提醒，由用户三选一：
     > “我发现《XX》很可能是**多人合写稿**（＜具体原因，如：内部有 2 套母版 / 出现了多位汇报人＞）。
     > **提醒一下**：尽量不要把同事写的页面混进来，不然我会把别人的画风学成你的习惯。
     > 这份稿你想怎么处理？（共 1 个问题）
     > - **A. 一键去掉，这次暂不纳入提炼**（推荐最省心）
     > - **B. 保留它，但我标出哪些页是我写的**（直接回复页码如 `第9-14页` 或关键词；记不清回“帮我列章节”，我压成 ≤ 6 个章节块给你挑）
     > - **C. 我确认整份都是我自己写的**”
   - 若用户标出连续 ≥ 5 页独立章节，自动纳入局部第 1 层分页节奏提炼。

## 三、第 2 步：纯 L3 视觉与母版摸底 ＋ 1 页纯皮肤预览（不混 L1/L2）

1. 运行 `pptx_inspector.py scan` 在本地算完统计、剥离出 **1～N 套真实母版皮肤**（`extract_clean_master_pptx` 生成空白母版底稿 ＋ 精确色板参数）。
2. **明确分离，只做纯视觉确认**：用 `pptx_builder.py build --mode preview` 克隆真实母版，为每套主皮肤生成 **1 页明确标为《纯视觉皮肤预览》的样稿**（固定示范标题 + 小表 + 要点 + 3 步流程条），**绝不提前混聊 L1 场景或 L2 内容框架**，只请用户确认两件事（共 ≤ 2 题）：
   - ① 一共提炼出几套母版皮肤，哪些要保留入库？
   - ② 若检出旧稿存在文字过小（< 10pt）、贴边或框叠框硬伤，以后默认“按干净安全留白微调（推荐）”还是“100% 照原样紧凑”？

## 四、第 3 步：三层积木核心对话（L1 场景 → L2 多框架 → L3 绑定关系）

> 核心对话严格控制在 **≤ 2 轮（每轮脚本硬限 ≤ 5 题）**。满足「出现率 ≥ 85% 且独立样本 ≥ 5 份」才列为免问确认卡（关末 ≤ 5 行，允许划掉旧公司强迫习惯）。

1. **L1｜写稿场景确认与补充**：
   - 展示系统从旧稿中归纳的主要写稿场景（如 `例会与进展汇报`、`项目复盘与迭代`、`方案评审与立项`、`对外客户提案与宣讲`、`培训分享与答辩` 等）及各自常见页数与节奏；
   - 请用户**确认、改名、合并或口头补充样本里没有但平时常写的场景**（调用 `profile confirm-scenario` 入库）。
2. **L2｜逐场景确认多套单页框架（按置信度分级）＋ 表达习惯**：
   - **一个场景允许挂接多种单页框架**：
     - **高置信度**（跨多份稿稳定复现、排版健康）→ 自动拟纳入对应场景框架库，集中放一屏确认（不喜欢的划掉）；
     - **置信度一般**（少数页出现或略挤/硬伤）→ 亮出原稿出处（文件名+页码），**同时给出合理的框架微调建议**，让用户三选一：**按原样收 / 按建议优化版收 / 不收**（调用 `profile confirm-framework`）；
     - **偶发零散页** → 默认忽略不打扰。
   - 同步确认标题句式、数字口径与备注双通道等表达规则。
3. **L3｜母版皮肤与 L1/L2 的绑定关系确认**：
   - 逐套母版皮肤让用户拍板：是**默认绑定某些场景**（如写月会默认用蓝线皮肤），还是**保持独立随时切换**（调用 `profile bind-mask`）。
4. **核心轮结束的显式报数分叉闸**：
   - 脚本返回 `CHECKPOINT_CORE_DONE` 与精确 `remaining_optional_count`（及预计轮次），**必须原样报出剩余细节题数**，让用户选：**A. 先出试炼样稿直接开用，细节留日后改稿顺手学（推荐）**，或 **B. 继续答完**。

## 五、第 4～6 步：组合试炼、回执教学与反悔机制

1. **第 4 步｜三层组合试炼验收**：
   - 挑一组常用搭配（`L1 场景 + L2 对应框架 + L3 绑定母版`），交付《三层风格体检卡》（≤ 10 条）、《迷你分页规划微卡》（5～8 行）＋ 2～3 页真实母版试炼 `.pptx`；支持直接改保存或口述改（整块删流程图/表格必先反问确认防误学）。
2. **第 5 步｜脱敏入库 ＋ 完成回执教学（硬规定）**：
   - 规则过 `output_guard.py sanitize-rule` 脱敏入库（真实业务原句仅留 `03-我的PPT风格说明书.md`），刷新 `00-操作中心.md`。
   - **强制执行 `workspace_manager.py usage-guide`**，在完成回执里**简明扼要教会用户：每种已提取的场景怎么直接发起、5 档口令怎么点菜、怎么自由混搭和手改学习、以及随时问“怎么发起写 PPT”即可重看指南**。
   - 涉及全局安装时，显式亮明安装目录，并提示**新开一个对话窗口发 `检查 PPT-style 是否就绪`**（及查不到时的 4 步排查引导）。
3. **第 6 步｜增量更新与永久反悔**：
   - 新代表作按指纹增量分析；随时响应 `修改上一题`、`查看/删除第 N 条规则`、`回滚上个版本`、`恢复出厂`。
